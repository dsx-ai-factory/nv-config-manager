Validates network connections for a specific device by checking physical and logical connectivity.

## User Interface

### Form Inputs

Users interact with a simple two-step form:

| Field | Description | Selection Type | Required |
| :---- | :---------- | :------------- | :------- |
| **Site** | Choose the site containing the device | Single dropdown from available sites | Yes |
| **Device** | Select the specific device to validate | Single dropdown from devices in selected site | Yes |

## Workflow Execution

### Execution Stages

1. Validate hostname
1. Get device intended neighbors
1. Get device actual neighbors
1. Validate device neighbors

## Report

The report and CSV export include **Intended Interface Label** from the DCIM
and **LLDP Port Description** from the observed neighbor, alongside the intended
and actual interface names. Missing metadata appears as `--` in the table.
See [Interpreting the report](../../user-guides/cable-validation/index.mdx#interpreting-the-report)
for a hyper-reach port-metadata mismatch example.
