Discovers hosts connected to a switch through its MAC forwarding table and LLDP neighbors, then enriches the results with DCIM host metadata and intended interface labels.

## User Interface

### Form Inputs

| Field | Description | Selection Type | Required |
| :---- | :---------- | :------------- | :------- |
| **Site** | Filter the device list by site | Dropdown | Yes |
| **Tenant** | Filter the device list by tenant | Dropdown | No |
| **Status** | Filter the device list by device status | Dropdown | No |
| **Device** | Select the switch to inspect | Dropdown | Yes |

## Workflow Execution

### Execution Stages

1. `get_device_mac_table`: read the device's MAC forwarding table.
1. `get_device_neighbors`: read observed LLDP neighbors and intended far-end interface labels.
1. `get_connected_host_data`: join observations with DCIM host metadata and display the consolidated table.

The neighbor and final tables show **Intended Interface Label** beside **LLDP Port Description**. These are expected and observed values, respectively; the workflow does not validate a match or update host inventory. See the [Connected Host Metadata guide](../../user-guides/connected-host-metadata/index.mdx) for column meanings and troubleshooting.
