Performs comprehensive hardware health checks on Cumulus Linux and Arista EOS network devices including sensors, fans, and system components.

## User Interface

### Form Inputs

| Field | Description | Selection Type | Required |
| :---- | :---------- | :------------- | :------- |
| **Site** | Choose the site containing devices to validate | Single dropdown from available sites | Yes |
| **Roles** | Device types to include in validation | Multi-select from: switch, spine, leaf, mgmt | Yes |
| **Device Status** | Filter devices by operational status | Multi-select from: active, planned, failed, maintenance | Yes |
| **Tenant** | Tenant context for multi-tenant sites | Single dropdown from available tenants | Yes |

## Workflow Execution

### Execution Stages

1. Discover hardware components
1. Collect hardware metrics
1. Validate against thresholds
1. Generate health report
