# Maintainers

NVIDIA Config Manager is maintained by the NVIDIA Config Manager project team.

## Current Reviewers and Ownership

The current repository-wide reviewers are @dmathur0, @jojung1, @kxtran,
@polarweasel, @ryanheffernan, @spidercensus, @susanhooks, and @zsblevins.
They share review ownership of services, UI, installer, deployment, documentation,
and CI. [CODEOWNERS](.github/CODEOWNERS) is the authoritative routing configuration;
update this list when that configuration changes. Reviewer membership does not
itself grant repository administration or release permission.

See [Governance](GOVERNANCE.md#maintainer-membership) for membership changes.

## Responsibilities

- Triage issues and pull requests.
- Review code, documentation, CI, deployment, and release changes.
- Coordinate security disclosures through [SECURITY.md](SECURITY.md).
- Maintain release notes and public documentation.

## Escalation

Use GitHub issues and pull requests for normal project discussion. Do not use
public issues for vulnerabilities; follow [SECURITY.md](SECURITY.md).

Repository administrators own final maintainer membership.
